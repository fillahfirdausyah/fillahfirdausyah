## 👋 About Me

I'm a **DevOps Engineer & Tech Lead at [Prestisa](https://github.com/prestisa)** based in Indonesia 🇮🇩. I started as a full-stack engineer, so I'm comfortable on both sides of the fence: writing the services and running them in production.

- 🏗️ Own infrastructure, code review and deployments across a **polyglot microservices** architecture
- ☁️ Designing cloud architecture and engineering standards on **Google Cloud (asia-southeast2)**
- 💸 Driving **GCP cost optimization** and billing governance
- 🤖 Building internal tooling: deployment orchestration, infra monitoring dashboards, and AI agents for DevOps automation
- 📚 Currently learning **Go (Gin)** in depth and leveling up on **Kubernetes** and **observability**

> *"If you have to do it twice, automate it."*
